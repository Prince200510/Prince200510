## 🚀 Flagship Project

### 🗄️ CrownDB — Relational Database Engine in C++17
A file-based relational database engine built entirely from scratch — not a wrapper around SQLite, an actual implementation of the storage and query layers.

- Custom **binary storage engine** persisting databases/tables to disk in a hierarchical `.tbl` format
- Hand-written **SQL parser + execution engine** — `CREATE`, `DROP`, `ALTER`, `INSERT`, `SELECT`, `TRUNCATE`, filtering, projection, and aggregates (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
- **Login-protected session management** with per-user database ownership
- Ships as both an interactive **CLI** and an embeddable **C++ API** (`Crowndb.h`) for integration into other applications

`C++17` `Systems Programming` `File I/O` `Custom SQL Parser`
