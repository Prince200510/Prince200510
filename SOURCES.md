# Assets and factual sources

## Typography
- Space Grotesk, bold display type. Google Fonts upstream: https://github.com/google/fonts/tree/main/ofl/spacegrotesk . SIL Open Font License 1.1: `licenses/SpaceGrotesk-OFL.txt`.
- JetBrains Mono, regular. https://github.com/google/fonts/tree/main/ofl/jetbrainsmono . SIL Open Font License 1.1: `licenses/JetBrainsMono-OFL.txt`.
- Both fonts are instantiated from variable fonts, subset to used Latin characters, converted to WOFF2 and embedded as base64 in each SVG. No font request is made at render time.
