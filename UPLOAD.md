# Upload to GitHub

1. Open or create the public profile repository **Prince200510/Prince200510**.
2. Upload the contents of this ZIP at the repository root. Preserve the `assets/` and `licenses/` folders; do not put the files inside an extra `profile/` folder.
3. Commit the files. Your profile README will load the five relative SVGs.

## Exact file list to upload

- README.md
- assets/hero.svg
- assets/about-life.svg
- assets/stack.svg
- assets/id-dashboard.svg
- assets/connect.svg
- assets/static/hero.svg
- assets/static/about-life.svg
- assets/static/stack.svg
- assets/static/id-dashboard.svg
- assets/static/connect.svg
- licenses/SpaceGrotesk-OFL.txt

- UPLOAD.md

README.md chooses the five animated SVGs normally and the five static SVGs when reduced motion is requested. Upload both sets. Keep license and attribution files with the assets. The other files provide a local preview and documentation.

Open `preview.html` after extracting the ZIP to preview locally. Social cards are artwork; real clickable links sit below them in README.md and the preview. Animation behavior can differ across GitHub clients and browser accessibility settings. All text has a readable static state. Change `?v=1` to `?v=2` after future asset changes if a cached version persists.
